# Transmog AzerothCore

Vestidor y coleccion de transmog para servidores privados WotLK 3.3.5 (AzerothCore).

## Creditos

- **Original (DressMe):** [GetLocalPlayer](https://github.com/GetLocalPlayer/DressMe)
- **Modificado / unificado por:** [Lleguito](https://github.com/LleguitoWoW)
- Incluye funcionalidad tipo **TransmogTip** (tooltips New Appearance + TRANSMOG_SYNC)

## Instalacion

Copia la carpeta `TransmogAzerothCore` a:

```
World of Warcraft\Interface\AddOns\TransmogAzerothCore
```

Comandos: `/transmog`  |  `/transmogminimap`

## Funciones

- Catalogo completo de apariencias (Items.lua)
- Check en desbloqueadas, bloqueo de clic en el resto
- Sync por TRANSMOG_SYNC, equipo y TransmogTipList
- Barra de progreso, idiomas ES/EN, minimapa
